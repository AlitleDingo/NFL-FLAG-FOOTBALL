# NFL FLAG FOOT BALL SIMULATOR

## What is this?

this is a python project that simulaters NFL Flag Football in the terminal.

## How to run this program?

First, clone the githb repisitory by running 

```powershell
git clone https://github.com/AlitleDingo/flag_foot_ball.git
```

then navigate to the folder by running:

```powershell
cd flag_foot_ball
```

Then run the main file by running:

```powershell
python3 Flagfootball.py
```
