# NFL FLAG FOOT BALL SIMULATOR

## What is this?

this is a python project that simulaters NFL Flag Football in the terminal.

## Requirments

To run this program you will need only some basic dev tools:

- Git

- Python

These are the only tools needed to run the program.

## How to run this program?

First, clone the githb repisitory by running 

```powershell
git clone https://github.com/AlitleDingo/flag_foot_ball.git
```

Then navigate to the folder by running:

```powershell
cd flag_foot_ball
```

Then run the main file by running:

```powershell
python3 Flagfootball.py
```

## How this project is structured

The data for this project (json files), is stored in the data folder. These json files include stuff such as the playbook, the hints, and the penalties. The other 2 files are flagfootball.py and ai.py.  Flagfootball.py contains the main code that brings the ai and the data together and prints the resault in the terminal. Ai.py just contas the algorith that tetermines what the opponet will do.
